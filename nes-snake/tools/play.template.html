NES SNAKE

红白机 / FC 原生的贪吃蛇 6502 ASM MAPPER 0 · NROM-256 NTSC 60Hz
状态：标题画面

键盘操作

移动↑↓←→ / W A S D
开始 / 暂停Enter 或 空格
回标题Shift 或 Backspace
本地暂停P
A / BZ / X

虚拟手柄

先点 START 开局
方向键轻点一下即可，无需长按

玩法

按 START 开局，方向键控制蛇吃红色宝石。
撞墙或咬到自己即 GAME OVER。
每吃 5 个升一级并加速；分数与最高分实时显示。
游戏中按 START 暂停，SELECT 回到标题。

关于

这是真正跑在 6502 模拟器上的 .nes ROM，不是网页仿制版。 画面由 PPU nametable + CHR-ROM 逐 tile 还原，声音来自 APU 方波与噪声通道。 首次按键后浏览器才允许播放声音。

NES SNAKE · 纯 6502 汇编 / ca65 + ld65 / 32KB PRG-ROM + 8KB CHR-ROM / iNES mapper 0
源码、CHR 图块生成器、构建脚本与 ROM 均在同一目录中；play.html 为自包含试玩页，可直接离线打开。
