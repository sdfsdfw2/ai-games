# NES Dual-Cart Collection (2026)

**Online: https://sdfsdfw2.github.io/ai-games/nes-dual-cart/**

Two homebrew NES ROMs written in pure 6502 assembly, playable directly in the browser.

- **index.html** is fully self-contained: jsnes, both ROMs and both CHR banks are inlined.
- Switch cartridges with the buttons at the top: **Snake** / **Music Box**.
- Music Box: 20 chiptune tracks synthesized live on the 4-channel 2A03 APU.
- **snake.nes** / **music.nes**: NROM-256, 40,976 bytes each, run in any NES emulator.

Controls: Arrow keys or WASD = D-pad, Z = A, X = B, Enter = START, Shift = SELECT.
URL parameters: `?game=music` / `?game=snake`, `?start=1` (auto-start Snake).

Built in 2026. Soundtrack: public-domain classical/folk themes + original chiptunes.
